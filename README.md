# 映小助 VideoFlow

**导入素材和文案，把混剪、配音、字幕和抖音发布串成一条流程。**

面向商家和内容创作者的短视频自动化桌面工具。

## 当前状态

公开仓库已建立，开源版正在整理。当前仅提供项目介绍，尚未上传源码、安装包或确定开源许可证；以下为计划开放的入门版范围，不代表本仓库已提供可运行版本。

## 计划开放的功能

- 素材混剪与近期镜头避让。
- 本地文案批量导入，顺序或随机选用。
- 系统中文配音，可设置字幕字体、颜色、字号和每行字数。
- 背景音乐随机、顺序或指定选择。
- 单个抖音账号的即时、定时与间隔发布。
- 任务状态、成片与错误信息查看。
- 视频和背景音乐引用原文件，减少重复复制。

## 使用流程

登录账号 → 导入素材文件夹 → 导入文案 → 设置数量与时间 → 一键制作并安排发布。

首次登录及平台要求的扫码、验证码由用户在官方页面完成。本机等待发布的任务需要电脑保持运行。

## 开源范围与边界

计划开放不含商业激活系统的入门版。多账号、多平台、AI文案和模型配音属于进阶版方向，不在当前开源范围内。

混剪按片段规则组合素材，不保证画面与每句话语义对应。平台页面变化可能影响自动发布；结果不明时应先核对，避免重复提交。
